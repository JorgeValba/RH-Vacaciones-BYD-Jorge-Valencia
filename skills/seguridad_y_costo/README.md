## Propósito y relación con la guía

Guía p.7: SKILL.md específico, ejemplos, versión y carga.

## Qué contiene y en qué formato

| Archivo o carpeta | Formato | Qué contiene y qué hacer con él |
|---|---|---|
| [SKILL.md](SKILL.md) | Markdown (.md) | Archivo Markdown real del skill; incluye metadatos, activador, fuentes, pasos, ejemplos y aceptación. |

## Cómo utilizarlo

Abrir SKILL.md y descargar su archivo sin procesar, o descargar el repositorio conservando esta carpeta. El formato Markdown renderizado sigue siendo el archivo real .md.

## Entorno y configuración

Para un consumidor de skills compatible, seleccionar su carpeta/archivo conforme a su mecanismo. En este proyecto Node lo lee con cargarSkills; n8n utiliza un snapshot, no una instalación automática desde GitHub.

## Validación y resultado esperado
